# website

Source code for Gonzalo Ríos' personal website.

The site is bilingual (English at `/`, Spanish at `/es/`), accessible to screen-reader and keyboard users, and exposes a Markdown version of every page (e.g. `/contact` → `/contact.md`).

## Status

Early setup. The stack and build instructions will be documented here once they are decided.

## Standards

- **Accessibility:** WCAG 2.2 AA minimum; Lighthouse accessibility 100 and zero axe violations.
- **Internationalization:** English (default) and Spanish, with `hreflang` alternates and fully localized copy, metadata and media.
- **Encoding:** UTF-8 everywhere.
- **SEO:** `sitemap.xml`, `robots.txt` and `llms.txt` are kept current.
- **Assets:** WebP images, lightweight video, self-hosted WOFF2 fonts.
